# T66 Audio System

Single reference for how audio works in T66, what is wired today, and how to replace any
placeholder sound or track with a professional one later. Updated 2026-06-09.

## Architecture

Two GameInstance subsystems own all audio:

| System | File | Role |
|---|---|---|
| `UT66AudioSubsystem` | `Source/T66/Core/T66AudioSubsystem.*` | Data-driven SFX router. Gameplay/UI code fires an **event ID**; the subsystem resolves it through `DT_AudioEvents` to sound assets with volume bus, pitch variance, and replay throttling. |
| `UT66MusicSubsystem` | `Source/T66/Core/T66MusicSubsystem.*` | Music state machine. Resolves tracks **by folder convention** (below) with async preload, fades, and looping. |

Volume settings (Master/Music/SFX, mute-unfocused) live in `UT66PlayerSettingsSubsystem`
and apply to both systems via the `SC_Music`/`SC_SFX` sound classes and component volume.

### Music priority model

```
Stinger (one-shot, owns the channel until finished)
  > Boss      (RunState boss active)
    > Area    (NPC safe-zone bubble overlap, last-entered wins)
      > Base  (FrontendLevel: MainTheme | Gameplay: Hero theme > Stage theme > Theme)
```

### Music folder contract (drop a file in → it plays; no code, no DataTable)

| Context | Folder | Notes |
|---|---|---|
| Frontend menu | `/Game/Audio/OSTS/MainTheme` (asset) | pre-existing |
| Gameplay default | `/Game/Audio/OSTS/Theme` (asset) | pre-existing |
| Hero theme | `/Game/Audio/OSTS/Heroes/<HeroKey>/` | **HeroKey = Heroes.csv `MapTheme` column**, not HeroID. Hero_1 → `Heroes/Hero_4/`. Outranks stage themes. |
| Stage theme | `/Game/Audio/OSTS/Stages/Stage_<NN>/` | NN = global stage number (Easy = 01–04). |
| Boss theme | `/Game/Audio/OSTS/Bosses/<BossID>/` | BossID = DT_Bosses row name (e.g. `Dungeon_WebMatriarch`, `VendorBoss`). Legacy `Bosses/Special/<BossID>/` still resolves. |
| NPC area theme | `/Game/Audio/OSTS/Areas/<NPCID>/` | NPCID = DT_NPCs row (`VendorNPC`, `CasinoNPC`, `Saint`, `Ouroboros`, `LoanShark`). Plays while the hero is inside that NPC's safe-zone bubble. |
| Stingers | `/Game/Audio/OSTS/Stingers/<ID>/` | `Victory`, `Defeat`. One-shot; base music resumes after. Preloaded at startup. |

The subsystem picks the first (alphabetical) SoundWave/SoundCue/MetaSound found in the
folder. The source `.ogg` lives in the same Content folder as its imported `.uasset`.

## SFX events

All SFX rows are generated by `Scripts/SetupAudioEventsDataTable.py` →
`Content/Data/AudioEvents.json` → `DT_AudioEvents`. Sounds come from the licensed
**Helton Yan Pixel Combat** pack (zip in Downloads / `SourceAssets/Audio/HeltonPixelCombat/Selected`).

Pre-existing coverage: UI clicks (5), per-hero attacks (12+5 fallbacks), ultimates (18),
per-enemy-type hits/deaths, boss projectile/AOE per archetype, traps (8), pickups,
chest/crate/totem, jump/dash, hero damage.

Added 2026-06-09 (event ID → call site):

| Event | Fires from |
|---|---|
| `Idol.Equip` | `UT66IdolManagerSubsystem` equip/altar/stock commits |
| `Idol.LevelUp` | idol tier upgrade via stock offer |
| `Saint.Blessing` | `UT66RunStateSubsystem::BeginSaintBlessingEmpowerment` |
| `Shop.Buy` / `Shop.Sell` / `Shop.Deny` | `T66RunStateSubsystem_EconomyInventory.cpp` buy/sell/buyback commits and gold rejections |
| `Casino.Bet` / `Casino.Win` / `Casino.Lose` | `T66CasinoGamblerTabWidget` bet lock + round resolution (all four mini-games funnel through it) |
| `Hero.Death` | `AT66PlayerController::OnPlayerDied` (also triggers `Defeat` stinger) |
| `Run.Victory` | `AT66PlayerController::ShowVictoryRunSummary` (also triggers `Victory` stinger) |
| `Run.StageAdvance` | `T66GameMode_Bootstrap.cpp` on arriving at the next stage |
| `UI.Pause.Open` | `UT66PauseMenuScreen::OnScreenActivated` |
| `UI.PowerUp.Open` / `UI.PowerUp.Confirm` | PowerUp screen open / purchase success (failures play `UI.Deny`) |
| `UI.Hover` | `FT66Style::MakeButton` hover (quiet tick; FlatStyle buttons have no hover handler, so no hover sound there) |

Area music push/pop hooks live in `AT66NPCBase::OnSafeZoneBeginOverlap/EndOverlap`
(every DT_NPCs actor gets this for free via its bubble).

## How to replace placeholder audio with professional audio

**Music / OST:** overwrite the `.ogg` at its contract path (table above), keep the
filename, then run:

```
UnrealEditor-Cmd.exe C:/UE/T66/T66.uproject -run=pythonscript -script="C:/UE/T66/Scripts/ImportGeneratedOSTs.py"
```

That re-imports every OSTS ogg in place. Adding music for a NEW boss/stage/hero/NPC is
the same: create the folder per the contract, drop the file, import. Zero code changes.

Run import commandlets with the Unreal editor CLOSED — an open editor holds file handles
on streaming SoundWaves and blocks the in-place re-save (LogSavePackage "Error moving
file" → commandlet exits 1 even though other assets imported fine).

Both import scripts preload the engine audio decoder modules (`unreal.load_module`,
BinkAudioDecoder et al.) — commandlets have no audio device, and without the preload the
first imported SoundWave trips a "Decoder for AudioFormat 'BINKA' not found" ensure that
fails the exit code. Keep that preload if you write new audio import scripts.

**SFX:** two options.
1. Swap the mapping: edit the event's `Patterns` in `Scripts/SetupAudioEventsDataTable.py`
   to point at different pack sounds, re-run the script (headless, same commandlet form).
2. Swap the file: replace the normalized WAV in `SourceAssets/Audio/HeltonPixelCombat/Selected/`
   (keep the name) and re-run the script.

**Placeholder OST regeneration:** `python Scripts/ComposeT66PlaceholderOSTs.py`
(deterministic; needs numpy/scipy/ffmpeg, no Unreal). Edit the `TRACKS` catalog in that
script to retune style/key/tempo per track.

## Known quirks

- `Heroes.csv MapTheme` is a permutation (Hero_1→Hero_4, Hero_5→Hero_1, …). The music
  folder key follows MapTheme, so Hero_1's theme sits in `Heroes/Hero_4/`.
- A hero theme masks stage themes for that hero (hero outranks stage by design — only
  Hero_1 has a theme, so stage themes are audible for the other 11 heroes).
- The legacy hero OST at `OSTS/Heroes/Hero_AliceInWonderlandRabbit/` matches no current
  MapTheme key and appears unreachable (see pending issues).
