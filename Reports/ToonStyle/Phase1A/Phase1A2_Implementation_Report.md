## Track 1 - Reusable Import Pipeline

Created `T66/ToonStyle/BlenderScripts/extract_and_normalize_pixal3d.py`.

The Blender stage imports a raw Pixal3D GLB, extracts embedded images to PNG, joins meshes, centers XY, puts the lowest vertex at Z=0, scales the mesh to a target height of 180 Blender units, applies transforms, strips texture references from export materials, and exports an FBX plus manifest JSON. The unit-scale fix is the critical part: FBX export uses `global_scale=0.01`, `apply_unit_scale=True`, `apply_scale_options="FBX_SCALE_ALL"`, and `bake_space_transform=False`. That is what prevents the Phase 1A.1 100x UE import mismatch.

Created `T66/ToonStyle/Source/ImportPixal3DAsset.py`.

The UE stage reads the Blender manifest, imports the FBX as a static mesh, rejects empty imports, rejects bounds outside 180 UU +/- 10%, imports PNG textures, creates a material instance parented to `/Game/Materials/M_GLB_Unlit`, binds `DiffuseColorMap` and `BaseColorTexture`, assigns the MI to slot 0, saves packages, and writes `<asset>_ue_verify.json`.

Created `T66/ToonStyle/Tools/RunPixal3DToUE.ps1`.

The orchestrator runs Blender first and then UE Editor Python. UE sometimes saves/imports successfully and then exits nonzero during shutdown due the known `ModeManagerInteractiveToolsContext None` headless editor crash. The orchestrator treats that as success only if the verification JSON exists and confirms valid bounds, texture import, material instance, and slot assignment.
