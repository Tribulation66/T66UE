# Enemy/Boss Placeholder Archive

This folder preserves the old placeholder roster sources that were removed from the live data pass on 2026-05-07.

Archived files:

- `Stages.placeholder-23row.csv`: old 23-row stage table using `Roost`, `Cow`, `Goat`, and `Pig`.
- `Bosses.placeholder-boss-number-roster.csv`: old numbered `Boss_##` placeholder boss rows.
- `PlayerExperience.old-stage-anchors.json`: old difficulty starts `1/6/11/16/21` and Impossible ending at stage 23.
- `CharacterVisuals.with-placeholder-enemy-rows.csv`: old visual table with the four placeholder enemy rows.
- `DefaultT66PlayerExperience.old-stage-anchors.ini`: old config comments and stage anchors.
- `DefaultT66StageProgression.old-impossible-3-stage-comment.ini`: old Impossible three-stage comment.

The live roster source is now under `Content/Data` with contiguous stages `1..20`, five enemies per difficulty, named boss encounters, and status-effect rows.
