# WorldNpcInteractablesRetroBatch01 archived references

This folder preserves live visual references before replacing placeholder/older interactable and NPC mesh paths with the WorldNpcInteractablesRetroBatch01 Quad Retro assets.

- `ArcadeInteractables.pre_world_npc_retro_batch01.json` is a full copy of the arcade interactables JSON before this update.
- `CharacterVisuals.pre_world_npc_retro_batch01.csv` is a full copy of the character visuals CSV before this update.
