# Retro FX Settings Tab Deprecation

Date archived: 2026-06-07

The Retro FX Settings tab is no longer player-facing. Settings now opens to Gameplay by default, the Retro FX tab button is not rendered, and command-line requests for `RetroFX` are redirected to Gameplay.

Retro FX subsystem and preview-popup compatibility code remains in place for existing inline/legacy flows.
