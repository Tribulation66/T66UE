# Auto-Attack Projectile ImageGen Prompts

Use built-in ImageGen. Save each final image to `Inputs/source_images/<projectile_id>.png`.

Shared negative prompt for every image:

```text
No character, no hands, no text, no labels, no watermark, no particles, no lightning, no fire, no magic, no glow, no motion trail, no action scene, no environment, no floor, no cast shadow, no contact shadow, no reflection, no pixel art, no blurry output, no cropped object, no duplicate objects.
```
