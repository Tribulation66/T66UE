# TD Runtime Source Assets

Mode-owned loose runtime art for the TD minigame lives here.

The current closed-loop pass uses ROTMG-style loose PNGs under:

- `Heroes/Singles`
- `Enemies/Singles`
- `Bosses/Singles`
- `Maps/Backgrounds`
- `UI/td_main_menu`

`ROTmgPixelSetManifest.json` records the source atlas and derived runtime files.
