## Five-Family Visual Ledger

Source manifest: `UI/FriendslopStyle/Screens/MainMenu/element_manifest.md`

| Metric | Count / Path | Notes |
| --- | --- | --- |
| Visual families evaluated |  | Must be 5: TopBar, LeftSocialPanel, RightLeaderboardPanel, CenterButtonStack, Background. |
| Visual family PASS |  | PASS means no regeneration needed. |
| Visual family FAIL |  | FAIL means regenerate this family in the current iteration. |
| Failed-family element PASS |  | Sum of elements checked inside failed families that do not need regeneration. |
| Failed-family element FAIL |  | Sum of elements inside failed families that must be generated by the family worker. |
| CLI workers launched |  | Must equal visual family FAIL count. |
| Textless reference breakdown |  | Must point to the CLI worker output and five family crop paths for this approved reference. |
| Generated family assets implemented |  | Must list source/runtime/staged implementation paths below. |
| Sizing/fitting work performed |  | Summarize changed spacing, sizing, containment, slicing, and live text/icon placement. |
| Sizing/fitting blockers |  | List blockers or `none`. |
| Wiring/functionality family PASS |  | Technical gate count. |
| Wiring/functionality family FAIL |  | Technical gate count; any fail makes the wiring/functionality gate FAIL. |
| Unreviewed families |  | Must be 0. |

## Family Element Breakdown

Use one block per family, in this exact shape. The bold heading names the family
and its family verdict. The table has exactly two columns so reviewers can
audit element coverage without scanning prose.

**TopBar family - FAIL**

| Element | Visual PASS/FAIL |
|---|---|
| Topbar outer shell | FAIL |
| Topbar icon plates | FAIL |
| Topbar tabs | FAIL |
| Ticket badge | FAIL |

Repeat the same format for `LeftSocialPanel`, `RightLeaderboardPanel`,
`CenterButtonStack`, and `Background`. Keep worker instructions and reasons out
of these tables; record them in the worker queue or notes sections.
