# T66 UI Content Stubs Registry

This registry tracks temporary generated content artwork used by the flat UI pipeline when production artwork is missing.

Content stubs are not chrome. Panels, borders, button plates, tab plates, dropdown shells, frames, dividers, tracks, and other chrome must be Slate-native through `FT66FlatStyle`.
